## Discussion sur Hacker News (184 commentaires)

**Avis positifs** :
- Apple Intelligence offre des capacités locales impressionnantes pour la confidentialité, avec des garanties techniques verifiables via Private Cloud Compute et divulgation open source
- Les fonctionnalités peuvent être pratiques pour certains utilisateurs (contexte personnel dans Siri, recherche dans emails/messages, rappels intelligents)
- Contrairement à Microsoft, Apple permet réellement de refuser les fonctionnalités sans forcer de compte cloud obligatoire pour utiliser le Mac

**Avis négatifs** :
- Les 8-16 GB de modèles IA restent dormants sur le disque et ne sont pas récupérables, ce qui est particulièrement problématique sur les petits disques M1/M2
- Les paramètres sont intentionnellement cachés sous Screen Time → Content & Privacy Restrictions plutôt que dans Privacy & Security, rendant la découverte quasi-impossible pour les utilisateurs non-parents
- Apple a atteint le niveau de 'crapware' de Microsoft : après démarrage, il faut désactiver manuellement une longue liste de fonctionnalités non consentis pour retrouver de l'autonomie
- Les fonctionnalités sont souvent peu intelligentes (suggestions d'emoji ridicules) et Siri reste globalement peu fiable malgré 15 ans de développement, contredisant le battage médiatique
- C'est un modèle de consentement inversé : les fonctionnalités devraient être désactivées par défaut, pas à l'utilisateur de les éteindre après avoir occupé son espace disque
