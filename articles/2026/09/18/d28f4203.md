## Discussion sur Hacker News (200 commentaires)

**Avis positifs** :
- Jev représente une approche novatrice forçant à être explicite sur les demandes et les options disponibles, ouvrant les yeux sur la demande d'applications dans ce segment de marché.
- La technique de classification seq-to-1 (entrée fixe, sortie unique) est conceptuellement valide et plus efficace que les LLM générativistes pour les tâches de décision structurées.
- Les performances observées (latence ~100ms, coûts réduits) permettent des use cases intéressants : contrôleurs d'IA, modèles pour jeux/robotique, décideurs génériques.
- L'entraînement sur données synthétiques à 100% est encourageant pour la reproductibilité et les alternatives open-source.
- Des implémentations légitimes émergeront rapidement via des patches vLLM et des modèles fine-tunés, démocratisant la technique.

**Avis négatifs** :
- OpenJev n'est pas Jev : c'est un projet qui émule le comportement avec des petits LLM standards (Qwen, MiniCPM), ce qui est trompeur et légalement risqué pour l'utilisation du nom.
- Les performances avec les petits modèles sont lentes (0,5-2 secondes) et peu impressionnantes comparées aux LLM existants, ne justifiant pas l'enthousiasme.
- OpenJev reste vulnérable à l'injection de prompts : affirmer qu'on « ne peut pas halluciner » est faux si les données non fiables peuvent influencer les probabilités.
- Les probabilités de sortie ne sont pas bien calibrées sans fine-tuning supplémentaire, et les résultats sont instables (coinflips rapides plutôt que vraies décisions).
- Le site lui-même est un exemple de contenu généré par IA maladroit : texte verbeux sans valeur, design générique, UX confuse—la substance de OpenJev ne rattrape pas ces défauts.
