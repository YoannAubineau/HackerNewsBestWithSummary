## Résumé de l'article

Laya est un modèle de décision structuré open source (licences Apache 2.0) conçu pour les tâches de classification, routage et triage. Contrairement aux modèles génératifs autorégressifs, il produit en 30-35 ms des probabilités calibrées sur des schémas structurés sans générer de texte ni halluciner.

- Trois primitives de décision : « choice » (sélection parmi options), « score » (notation ordinale), « noul » (question booléenne) ; sorties exclusivement numériques, jamais du texte
- Trois points de contrôle spécialisés (anglais, décisions typées, multilingue 100+ langues) bundlés dans un seul dépôt Hugging Face avec téléchargements sélectifs par sous-dossier
- Routage linguistique intégré en < 1 ms basé sur détection de scripts Unicode (dévanagari, CJK, cyrillique, arabe, hébreu, etc.), essentiel car les modèles anglophones affichent une confiance élevée (~95%) tout en échouant massivement sur alphabets non-latins
- Performances mesurées en production : 0.993 précision sur filtrage spam (Enron), 0.980 sur phishing, 0.755-0.762 sur garde-fous LLM (jailbreak) ; limitations connues sur > 20 options de choix (Architecture : tête partagée sur 192-256 tokens) et nécessité d'affinage sur données métier
- Accès complet : package PyPI (laya>=0.3.3), hub Hugging Face, démo interactive, dépôt GitHub, carnet Kaggle pour affinage sur GPU libre

## Discussion sur Hacker News (135 commentaires)

**Avis positifs** :
- L'open-source de Laya offre une alternative à Jev dans un domaine où des solutions fermées dominent injustement le marché et reçoivent une visibilité disproportionnée.
- Laya/hallunox repose sur une recherche rigoureuse publiée il y a un an (arxiv 2510.01237), démontrant que cette classe de modèles 'System One' était déjà connue avant le battage marketing de Typesafe.
- Ces petits modèles spécialisés répondent à un réel besoin : classification efficace, pas d'hallucinations structurées, coûts drastiquement réduits comparé aux LLMs pour des tâches spécifiques.
- Le projet illustre comment la communauté ML retrouve de la valeur dans les fondamentaux (BERT optimisé, classifieurs généralisants) plutôt que de tout forcer dans les LLMs génériques.
- L'initiative crédibilise la recherche académique et de communauté contre une tendance où le financement VC et le marketing éclipsent les contributions open-source établies.

**Avis négatifs** :
- La fenêtre de contexte de Laya (512-1024 tokens) est bien inférieure à celle de Jev (64k), ce qui limite fortement les cas d'usage réels comparé à la solution commerciale.
- Laya n'est pas véritablement 'la version open-source de Jev' : elle utilise ModernBERT (~400M paramètres), tandis que Jev semble être un modèle beaucoup plus grand avec capacités 'frontier'.
- Le papier arxiv original de l'auteur décrit un pipeline spécifique (RAG, embeddings, orchestrateurs) pour un cas métier particulier, pas un classifieur généralisé ; les comparaisons directes sont douteuses.
- Les tests simples de Laya révèlent des faiblesses : incapacité à raisonner sur les probabilités, hallucinations sur les nombres, outputs incohérents même pour des questions triviales.
- L'amertume de l'auteur occulte que productifier et communiquer efficacement une technologie est un travail différent et distinct de la recherche ; Jev a résolu un problème de timing/marché que la publication arxiv seule ne résout pas.
