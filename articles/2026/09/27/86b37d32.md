## Résumé de l'article

Drawgent est un outil qui connecte un agent de codage (Claude Code, Codex ou Opencode) à un tableau blanc Excalidraw interactif. L'agent peut éditer le diagramme en temps réel en réponse aux demandes de l'utilisateur ou à des instructions écrites directement sur le canvas (préfixées par AGENT:), et lier les formes du diagramme aux portions de code correspondantes dans le projet.

- L'agent reçoit des captures d'écran du canvas et peut proposer des modifications via un chat dans le panneau latéral, ou être déclenché par des notes AGENT: annotées sur le diagramme
- Les formes peuvent être liées au code (fichiers, plages de lignes, symboles), ce qui permet de parcourir le code depuis le diagramme et de vérifier que les liens restent synchronisés
- L'utilisateur peut pointer sur le code via un laser ou des sélections pour l'ajouter au contexte du chat, sans avoir à taper des chemins de fichiers
- Drawgent détecte les changements au diagramme et permet à l'agent de modifier le code pour les matcher ; les changements sont marqués avec des indicateurs de progression (planifié → en cours → terminé)
- Plusieurs tableaux peuvent coexister dans un workspace, stockés comme fichiers .excalidraw standards versionnable en git, ou hébergés sur excalidraw.com avec chiffrement end-to-end

## Discussion sur Hacker News (45 commentaires)

**Avis positifs** :
- L'interaction en direct sur un canvas visuel avec un agent offre une collaboration novatrice pour brainstormer architectures et prototypes UI, accélérant l'itération de conception
- Les outils de diagramme comme Excalidraw avec MCP permettent aux modèles d'accéder à des formats semi-structurés et d'ajuster rapidement des visualisations à base de feedback
- Les diagrammes apparemment dessinés à la main obtiennent davantage d'engagement et d'attention du public comparé aux contenus générés visiblement automatisés
- Cette approche aide les équipes à identifier les lacunes en connaissances et les hypothèses implicites en visualisant collectivement l'architecture

**Avis négatifs** :
- Les diagrammes générés par les agents manquent encore de qualité et ressemblent à du 'slop' ; les modèles ne savent pas quels éléments mettre en avant ou simplifier
- L'agent sketching n'offre pas d'avantage réel comparé à coder directement ; c'est surtout une interface UI novatrice plutôt qu'une accélération du développement
- Les outils de whiteboard actuels (y compris Excalidraw) ne sont pas assez adaptés aux agents ; les modèles maîtrisent mieux des formats comme Mermaid ou HTML pour générer des diagrammes
- Les agents peinent avec les niche formats et les calculs de boîtes englobantes en pixels ; HTML offre une meilleure sémantique naturelle pour l'itération visuelle
