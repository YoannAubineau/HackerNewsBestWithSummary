## Discussion sur Hacker News (204 commentaires)

**Avis positifs** :
- Les instances Nitter alternatives et décentralisées continueront à proliférer ; le code open source rend impossible une suppression totale malgré les poursuites juridiques
- L'accès sans compte est un besoin réel : de nombreux contenus publics (gouvernements, organisations) sont publiés exclusivement sur X, créant une barrière d'accès injustifiée à l'information publique
- X intentionnellement dégradé l'expérience non authentifiée pour forcer la création de comptes et la monétisation, rendant des outils tiers nécessaires pour un accès convenable
- L'asymétrie juridique est flagrante : les entreprises d'IA peuvent scraper impunément pour l'entraînement (transformative use) tandis que Nitter est poursuivi pour simple réaffichage non modifié

**Avis négatifs** :
- Nitter/XCancel redistribue directement le contenu d'X sans modification, ce qui diffère légalement du fair use transformatif utilisé par les LLM et les moteurs de recherche
- Le service prive X de métriques et d'impressions publicitaires même sans générer ses propres revenus, ce qui constitue une concurrence directe plutôt qu'une simple alternative d'accès
- La création de comptes de masse (même achetées) pour contourner les restrictions d'accès pourrait violer le Computer Fraud and Abuse Act et les conditions d'utilisation, rendant l'architecture même de Nitter juridiquement fragile
- Il existe des alternatives légales (créer un compte gratuit, utiliser Bluesky) ; insister sur l'accès sans friction revient à demander un accès gratuit sans contribution, ce qui contredirait tout modèle de plateforme durable
