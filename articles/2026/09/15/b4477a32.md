## Résumé de l'article

Capsule est un format et une plateforme permettant de créer des applications complètes (interface utilisateur, données, code) empaquetées dans un seul fichier .capsule portable. Les données sont stockées localement en SQLite sans connexion cloud, et le fichier peut être partagé par email, WhatsApp ou AirDrop comme un document PDF.

- Les applications Capsule fonctionnent entièrement hors ligne et restent privées ; toutes les données restent sur l'appareil de l'utilisateur sans serveur cloud
- Les fichiers .capsule sont multiplateformes et s'ouvrent nativement sur macOS, Windows, Linux, avec support iOS et Android en préparation
- Un assistant IA peut générer automatiquement une application complète à partir d'une simple description textuelle, et permettre des modifications ultérieures
- Le code et les actifs multimédias utilisent du HTML et CSS standard, restant la propriété entière de l'utilisateur
- Capsule est gratuit ; un lecteur hôte est disponible au téléchargement pour chaque plateforme

## Discussion sur Hacker News (114 commentaires)

**Avis positifs** :
- Résout un vrai besoin pour les petits outils personnels : alternative à Excel/SaaS pour tracker des recettes, du temps, de la facturation sans infrastructure serveur coûteuse
- Format portable comme un document (PDF, Word) : partage facile via USB, cloud storage, reste inchangé contrairement aux apps web qui dépendent d'une infrastructure
- Particulièrement adapté aux workflows d'IA génératives : permet de distribuer facilement des mini-apps créées par des agents LLM sans déploiement Docker/backend complexe
- Approche intéressante pour les contextes d'entreprise : alternative plus légère aux 10 000 petites apps à dockeriser, utilise le runtime une fois sur chaque machine
- Appuie un mouvement plus large : retour des apps desktop locales face à la fatigue SaaS et aux préoccupations de vie privée

**Avis négatifs** :
- Friction distributive majeure : nécessite d'installer une app 'viewer' propriétaire pour ouvrir les fichiers .capsule, contrairement aux navigateurs déjà présents partout (barrière similaire à Java Runtime)
- Problèmes sérieux de concurrence et fusion : partager des copies de fichiers crée des divergences de données difficiles à réconcilier, pire qu'héberger sur le web où l'état est centralisé
- Risques de sécurité et malveillance : fichiers exécutables portables ressemblent à des vecteurs de distribution de malware, préoccupations analogues aux .exe téléchargés
- Comparaison peu flatteuse à MS Access : crée des silos de données difficiles à maintenir pour les départements IT, ne sépare pas code et données contrairement à Access qui avait des templates
- Limites techniques actuelles : sur Mac le téléchargement affiche des erreurs ('fichier endommagé'), manquent des fonctionnalités clés comme les mises à jour d'app sans perte de données et la synchronisation multi-appareils
