## Résumé de l'article

Mistral, fournisseur de modèles d'intelligence artificielle, intègre par défaut les conversations et contenus des utilisateurs dans ses programmes d'entraînement de modèles, sauf pour les clients enterprise. Les utilisateurs peuvent désactiver cette collecte selon leur plateforme d'utilisation.

- Sur Vibe (via panneau admin) : désactiver le toggle « Allow your interactions to be used to train our models » dans la section Privacy
- Sur l'application mobile Vibe (iOS/Android) : aller dans Paramètres, Data & Account Controls, et décocher « Enable data sharing »
- Pour Mistral Studio et l'API : désactiver le toggle « Anonymous improvement data » dans le panneau admin pour bloquer l'utilisation des appels API à des fins d'amélioration
- Les clients enterprise sont exemptés de cette collecte de données par défaut

## Discussion sur Hacker News (119 commentaires)

**Avis positifs** :
- Mistral offre toujours un toggle pour désactiver l'entraînement sur les données, y compris pour les organisations via le tableau d'administration
- L'utilisation des données pour l'entraînement du modèle est une pratique standard dans l'industrie de l'IA; Claude et Gemini Pro font également cela par défaut
- Pour les modèles ouverts, Mistral propose une alternative souveraine européenne aux géants américains, avec davantage de contrôle réglementaire
- Le modèle GLM-5.2 offre de bonnes performances à bas coût tout en permettant d'éviter le partage de données si on désactive les paramètres

**Avis négatifs** :
- Mistral a discrètement inversé sa politique : le partage des données pour l'entraînement est passé de désactivé par défaut à activé par défaut pour les plans Team, sans communication claire
- L'absence de contrôle centralisé au niveau organisationnel pour les plans Team force les administrateurs à demander à chaque utilisateur de désactiver manuellement le partage, ce qui est impraticable et contre-productif pour les données sensibles
- Mistral s'est présenté comme une alternative respectueuse de la vie privée par rapport aux géants américains, mais applique les mêmes tactiques agressives de collecte de données que ses concurrents
- Les changements de politique et la documentation confuse créent de la méfiance : les utilisateurs découvrent leurs données partagées contre leurs attentes initiales, et les politiques de confidentialité évoluent sans transparence
- Les promesses légales de respect de la confidentialité se sont avérées insuffisantes dans la pratique; les entreprises violent régulièrement les politiques sans conséquences significatives
