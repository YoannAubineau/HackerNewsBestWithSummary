## Discussion sur Hacker News (122 commentaires)

**Avis positifs** :
- L'intégration IA automatise les tâches répétitives et fastidieuses (gestion d'assets, organisation de médias, synchronisation de fichiers) sans remplacer la créativité des éditeurs
- Cet outil abaisse la barrière d'entrée pour les débutants en rendant accessibles les tâches complexes tout en conservant le contrôle créatif humain
- BMD propose un modèle économique attrayant (licence unique à 295$ sans abonnement, upgrades gratuits, multiplateforme) contrairement aux concurrents par subscription
- L'IA permet aux créatifs de se concentrer sur les décisions artistiques plutôt que sur les tâches administratives, liberté similaire au progrès technologique passé
- Les utilisateurs rapportent des gains de productivité concrets (Claude via scripts Lua, MCP servers, transcription intelligente) pour leurs workflows réels

**Avis négatifs** :
- Le support Linux reste problématique (codecs manquants, installation complexe, limitations GPU) tandis que BMD priorise les fonctionnalités IA
- Le risque de remplacement progressif des créatifs professionnels : l'IA pourrait éventuellement gérer entièrement la création, pas seulement l'assistance, contredisant les promesses actuelles
- L'ajout de features IA ne résout pas les véritables limitations du logiciel (interface complexe, courbe d'apprentissage abrupte pour les vrais outils comme le color grading)
- La fonction créative est subjective et procédurale pour les artistes passionnés ; l'automatisation complète risque de produire du contenu généralisé sans caractère ('AI slop')
- Les coûts cachés et l'infrastructure des LLM externes (tokens, latence) pourraient finalement dépasser le coût initial du logiciel, particulièrement pour les petits projets
