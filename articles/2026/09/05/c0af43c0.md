## Résumé de l'article

CVE-2026-85046 est une vulnérabilité de confusion de type dans le moteur V8 de Google Chrome affectant toutes les versions antérieures à 152.0.7977.82. Elle permet à un attaquant distant d'exécuter du code arbitraire à l'intérieur du sandbox via une page HTML malveillante.

- La vulnérabilité a une gravité haute selon l'équipe de sécurité Chromium, avec un score CVSS 3.1 de 9.0 (accès réseau, pas de privilèges requis, interaction utilisateur nécessaire)
- Elle est activement exploitée et figure dans le catalogue CISA des vulnérabilités connues exploitées, avec une date limite de correction fixée au 18 septembre 2026
- La faiblesse sous-jacente est classée CWE-843 (accès à une ressource utilisant un type incompatible)
- Le correctif a été publié dans Chrome 152.0.7977.82 et les organisations doivent appliquer les mises à jour conformément aux directives CISA BOD 26-04

## Discussion sur Hacker News (197 commentaires)

**Avis positifs** :
- Le sandboxing de Chromium fonctionne comme prévu : une RCE dans le sandbox nécessite toujours une chaîne d'exploits supplémentaires pour affecter réellement le système de l'utilisateur, confirmant que la défense en profondeur fait son travail
- Chrome possède un excellent bilan de sécurité comparé aux autres navigateurs, avec une équipe d'ingénierie exceptionnelle et des efforts constants de durcissement depuis des années
- Le score CVSS de 8.8 est justifié car il requiert une interaction utilisateur (visiter une page HTML spécifique), ce qui l'empêche d'atteindre 10
- Les correctifs se déploient rapidement : plusieurs mises à jour Chromium (152.0.7977.82+) contiennent déjà le correctif, même si le déploiement complet prend du temps

**Avis négatifs** :
- La rémunération de 1 000 $ pour une vulnérabilité RCE activement exploitée est scandaleusement basse comparée à sa valeur réelle sur les marchés gris et risque de pousser les chercheurs vers la vente illégale
- Le titre 'tous les versions Chromium' est trompeur : sans distinction entre 'limite inférieure non testée' et 'affecte réellement tous les versions', typique des CVE navigateur qui ne font pas cette précision
- Normaliser l'exécution de code arbitraire (JavaScript/WASM) comme condition nécessaire pour accéder aux sites web a été une mauvaise décision qui perpétue les risques de sécurité
- La monoculture Chromium (Chrome, Edge, Brave, Electron) crée des risques systémiques où une vulnérabilité affecte potentiellement des milliards d'appareils et de contextes différents
- Il est flou si cette RCE exploitée en pratique inclut une chaîne d'escalade de privilèges complète ou si des 0-days de sandbox escape sont également en circulation
