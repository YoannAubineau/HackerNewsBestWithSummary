## Résumé de l'article

Pun est une plateforme d'hébergement de dépôts Git (publics et privés) basée entièrement en Europe, conçue pour offrir une alternative aux services américains tout en prioritisant la disponibilité et l'expérience développeur.

- Les données restent exclusivement dans l'UE sous droit européen, sans assujettissement au Cloud Act américain ni risque de verrouillage par un tiers distant
- La plateforme rejette les contributions automatisées de faible qualité (« slop »), refuse d'utiliser le code utilisateur pour entraîner des modèles d'IA, et n'impose pas de fonctionnalités IA
- Elle propose une API compatible GitHub (/api/v1) permettant une migration aisée des scripts existants, un CLI (pun) pour la gestion via terminal, et l'importation complète depuis GitHub avec historique, labels, issues et pull requests intacts
- La fiabilité et la disponibilité sont des priorités centrales, avec un engagement que les serveurs restent accessibles en permanence
- Les données peuvent être récupérées via git clone (copie complète du dépôt) et via l'API REST (issues, pull requests) ; une export en archive est planifiée

## Discussion sur Hacker News (121 commentaires)

**Avis positifs** :
- Besoin réel d'alternatives européennes : plusieurs utilisateurs confirmant la demande pour une solution Git hébergée en Europe, notamment après des déceptions avec d'autres plateformes
- Interface utilisateur remarquablement rapide et intuitive, surpassant GitHub et GitLab en réactivité, avec raccourcis clavier bien pensés
- Stack technologique solide (Elixir/Phoenix, Rust pour Git, stockage S3 sur serveurs bare metal à Paris) et implémentation Git innovante utilisant S3 compatible au lieu du stockage disque traditionnel
- Approche de gouvernance novatrice : système de réputation et de vouching pour filtrer les contributions low-quality, inspiré par la structure de confiance de Linus Torvalds
- Positionnement complémentaire : contrairement à Codeberg (FOSS uniquement), Pushin cible les projets commerciaux et privés nécessitant flexibilité sur l'IA générative

**Avis négatifs** :
- Manque critique de transparence au lancement : absence de politique de confidentialité, conditions d'utilisation, modèle tarifaire et informations légales, minant la confiance malgré les promesses techniques
- Terminologie confuse et imprécise : l'utilisation du mot « track » au lieu de « collect » et « store » crée des malentendus sur la collecte de données, renforçant les doutes sur la véracité des engagements
- Design perçu comme du « vibe coding » ou généré par IA, soulevant l'ironie d'une plateforme bloquant le slop IA qui elle-même en est accusée
- Limitations techniques non résolues : pas de support IPv6, dépendances américaines via Cloudflare (DNS), absence de DNSSEC, manque de détails sur les limites d'upload
- Confusions géographiques : le site amalgame « Europe » et UE sans clarifier explicitement où les données sont stockées, confusion renforcée par le registrar en Lituanie utilisant Cloudflare
