## Résumé de l'article

Un développeur a créé Beep Locator, un système logiciel utilisant Claude Code pour localiser un bip intermittent dans sa maison. Le système exploite plusieurs appareils connectés (iPads, phones, ordinateurs portables) qui écoutent simultanément et se servent les uns des autres pour calibrer leurs positions spatiales, puis appliquent la triangulation acoustique pour identifier la source du son.

- Le système fonctionne par triangulation : les appareils listeners enregistrent continuellement l'audio via WebSocket, détectent les bips avec une analyse FFT, et coordonnent leurs enregistrements en synchronisant autour d'un chirp de référence émis par un appareil
- Une interface web permet de placer manuellement les appareils en mode « rough », d'identifier les sons en écoutant les enregistrements de chaque device, et de marquer le bip cible pour affiner la localisation
- Le projet s'appuie sur la recherche académique BeepBeep (2007), qui décrit un système de ranging acoustique utilisant uniquement du matériel standard et des logiciels
- Claude Code a construit le système en Python et JavaScript via une session collaborative en mode Extra thinking effort, incluant la capacité à exécuter et modifier du code JavaScript à distance sur les appareils listeners sans interruption utilisateur
- Le système a localisé le bip à ±40 cm près, révélant un vieux détecteur de monoxyde de carbone ayant besoin de piles

## Discussion sur Hacker News (162 commentaires)

**Avis positifs** :
- Le projet démontre efficacement comment combiner audio, triangulation et agents IA pour résoudre des problèmes du monde réel de manière créative et rapide
- L'approche multiappareils (téléphones, tablettes, ordinateurs portables) utilisant des microphones ordinaires montre que les solutions sont accessibles sans équipement coûteux comme les caméras thermiques
- Le système offre une alternative pratique aux méthodes manuelles fastidieuses (recherche boîte par boîte, timing des bips) particulièrement pour les sons difficiles à localiser comme les bips de détecteurs de monoxyde de carbone
- Le code open source et l'approche documentée permettent aux autres de reproduire et adapter la technique pour divers cas d'usage (localisations de fuites, identification de sources sonores)

**Avis négatifs** :
- Pour de nombreux cas simples, les méthodes traditionnelles (écoute directionnelle, timing des intervalles entre bips, recherche manuelle) seraient plus rapides et demandent moins d'infrastructure qu'un système complexe multi-dispositifs
- La précision annoncée (40cm) est bien inférieure aux attentes initiales et démontre les défis pratiques de la triangulation acoustique en environnement fermé avec réflexions
- Le projet encourage une dépendance aux outils IA sans apprentissage en profondeur : analyser du code généré et comprendre l'audio sans maitriser vraiment les fondamentaux reste superficiel
- L'effort total (configuration multi-appareils, synchronisation, apprentissage du système) pourrait dépasser celui d'une simple recherche manuelle, surtout pour une problématique unique et non récurrente
