## Résumé de l'article

Un projet porte la fonctionnalité Loudness Equalization de Windows (issue de la DLL WMALFXGFXDSP.dll) vers PipeWire, le serveur audio moderne de Linux. L'outil égalise le volume de chaque application pour que les passages calmes et forts soient joués à des niveaux similaires, via un contrôle automatique de gain large bande associé à un limiteur de sortie.

- Composé de trois modules : un plugin de loudness équalization par application, un limiteur de sortie par appareil audio (inspiré d'AudioEng.dll), et une interface GTK3 optionnelle pour configurer les paramètres globalement ou par application
- Nécessite PipeWire ≥ 1.4 et GTK 3 ; installation simple via make et make install, avec commandes de configuration via pw-metadata
- Les paramètres sont stockés dans les métadonnées PipeWire et persistent entre les redémarrages ; les fichiers de configuration par défaut se trouvent dans /usr/share/pipewire/ et peuvent être surpassés localement
- L'implémentation détaillée utilise une FFT pour analyser la puissance spectrale en 25 bandes de fréquences, puis calcule un gain adaptatif jusqu'à +20 dB, avec un limiteur look-ahead de 64 frames pour éviter les pics
- Fonctionne sur les flux de lecture standard ; ne traite pas les clients JACK, les flux à plus de 8 canaux, ou les applications Flatpak utilisant PipeWire directement

## Discussion sur Hacker News (165 commentaires)

**Avis positifs** :
- Résout un problème concret : équilibrer les niveaux audio entre plusieurs applications simultanées (appels, notifications, musique) sans intervention manuelle constante
- Utile pour les configurations audio minimales (haut-parleurs de laptop, environnements bruyants) et pour les contenus mal mixés (films Christopher Nolan, dialogues inaudibles)
- La reverse-ingénierie elle-même représente une expertise technique intéressante et les connaissances acquises bénéficient à la communauté Linux audio
- Fonctionnalité simple à implémenter (algorithme court), déjà disponible via EasyEffects mais centralisée ici dans PipeWire avec exclusions par application
- Approche non intrusive : fonctionnalité optionnelle, désactivée par défaut, laissée au choix de l'utilisateur

**Avis négatifs** :
- Approche éthiquement douteuse : extraction directe du code Windows via IA plutôt que création indépendante, qualifiée de vol/piratage, qui contamine la confiance envers tout futur code similaire en open source
- Incompatible avec l'audio professionnel : les EQ/compresseurs système invisibles posent problème aux ingénieurs audio qui nécessitent du contenu non modifié ou des mesures précises
- Détruit la dynamique musicale intentionnelle : problématique pour les compositions avec plages dynamiques volontaires, les enregistrements masterisés, les opérations d'écoute attentive
- Crée des problèmes secondaires : limites non ajustables, latence ajoutée, interaction négative avec autres systèmes audio (downmixing 5.1 vers 2.0, loopback, outils de conférence)
- Solution incomplète : existait déjà via EasyEffects/Calf Studio Gear, ne représente donc pas une innovation majeure mais plutôt une commodité de centralisation
