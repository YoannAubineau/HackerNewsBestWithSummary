## Résumé de l'article

OmniDiff est un outil open source de comparaison (difftool) pour Git, écrit en Rust, qui traite les modifications de code de manière structurelle selon leur type de fichier. Il traite avec succès 99,95 % des modifications de code et utilise des algorithmes spécifiques au contenu pour 98,8 % des changements, tout en offrant une vitesse médiane de 4,2 ms et un 99e percentile de 177 ms sur plus de 2 300 fixtures de test.

- Support de 25 langages avec grammaires tree-sitter pour une comparaison structurelle; les autres fichiers sont traités comme texte brut ou analysés selon leur contenu (images, polices, archives, PDF, etc.)
- Installation via cargo, Homebrew, dépôts apt/deb, Nix, Arch et Gentoo; intégration disponible pour VS Code, Neovim, Git et Jujutsu (jj) avec visualisation interactive en TUI ou mode texte
- Interface utiliselle proposant plusieurs thèmes clair/sombre, support des graphiques kitty/sixel/iTerm2, navigation par contexte de fonction/classe et affichage de 3 lignes de contexte par défaut
- Modes de sortie en texte brut, JSON ou mode interactif; compatible avec GIT_EXTERNAL_DIFF pour intégration directe sans configuration difftool
- Licence AGPL v3 avec option commerciale par GitHub Sponsors; projet développé en partie avec assistance IA (Claude Code) de manière transparente et documentée

## Discussion sur Hacker News (67 commentaires)

**Avis positifs** :
- Algorithme différent et plus efficace que les outils existants : détecte le code déplacé, améliore significativement ~30% des diffs, et offre une précision de 90% vs 64% pour Difftastic
- Support multi-formats : traite non seulement le code (2/3 des diffs) mais aussi les images et autres formats de fichiers, avec affichage natif sur terminaux compatibles
- Performance supérieure : temps de traitement 8-10x plus rapide que Difftastic (4ms vs 35ms en p50, 420ms vs 637ms en p99)
- Choix politique de licence AGPL assumé : protège les libertés des utilisateurs contre l'exploitation commerciale et les versions propriétaires
- Très personnalisable : offre plusieurs modes de visualisation, paramètres ajustables et reconnaît l'importance des préférences visuelles individuelles

**Avis négatifs** :
- Licence AGPL décourage adoption par les développeurs et intégration dans les projets existants comparé aux alternatives MIT comme Difftastic ou Delta
- Fragmentation des installations : nécessite 3 méthodes différentes selon l'OS (deb, compilation, brew) contrairement à Delta disponible uniformément via gestionnaires de paquets officiels
- Manque de features visuelles comparé à Delta : pas d'équivalent au mode diff-so-fancy avec surlignage différencié ligne/caractère
- Crash sur fichiers pathologiques (matrices géantes encodées, PNG en array C++) au lieu de gérer gracieusement, bien que rare en pratique
- Préférences visuelles subjectives : certains utilisateurs ne trouvent pas l'output meilleur que les alternatives existantes malgré les métriques affichées
