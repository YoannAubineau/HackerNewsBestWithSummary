## Résumé de l'article

Un projet présentant une implémentation complète de l'architecture DeepSeek-V3 (un grand modèle de langage avec mélange d'experts) en JAX pur sans dépendances externes, entraîné sur un MacBook Air M5 avec des textes de détectives du domaine public. Le code réimplémente le modèle original (671 milliards de paramètres) en version réduite (36,2 millions de paramètres) avec 6 couches et un contexte de 256 tokens.

- L'architecture utilise le Dense MoE (Mixture of Experts), où chaque expert s'exécute sur chaque token et ceux non sélectionnés sont mis à zéro ; aucun dispatch creux ou parallélisme expert n'est implémenté
- Le code est entièrement fonctionnel : les paramètres sont des dictionnaires simples de tableaux et chaque composant peut être lu de haut en bas dans le fichier principal
- Les résultats d'entraînement incluent une perte de validation de 3,921 après 2000 étapes ; le modèle génère du texte cohérent mais reste une démo d'architecture plutôt qu'un modèle de langage robuste
- Installation et utilisation entièrement reproductibles : checkpoints, données tokenisées et scripts d'entraînement/échantillonnage fournis avec versions Python 3.12 et JAX épinglées
- Démonstration d'ablations incluant l'impact du biais d'équilibre des experts et comparaisons avec exécution sur CPU ou backend ROCm

## Discussion sur Hacker News (25 commentaires)

**Avis positifs** :
- Excellente ressource pédagogique : recréer un modèle from scratch aide à vraiment comprendre les principes plutôt que de les lire passivement, avec visualisations et diagrammes
- Approche pratique et accessible : JAX simplifie l'implémentation (gradients automatiques, compilation) et permet l'entraînement sur du matériel modeste (MacBook Air M5, GPU consumer AMD RX 7600 XT)
- Documentation exceptionnelle : writeup détaillé avec diagrammes, résultats empiriques, checkpoint entraîné et données publiques rendent le projet entièrement reproductible
- Démonstration utile des innovations de DeepSeek V3 : latent attention multi-head, load balancing par bias au lieu de loss auxiliaire, et multi-token prediction présentées clairement et simplement

**Avis négatifs** :
- Utilisation de données non-standard (romans policiers old school) rend difficile la comparaison des résultats avec d'autres implémentations, idéalement il faudrait des datasets publics reconnus
- Écosystème JAX/AMD reste problématique : nécessite des workarounds spécifiques (env vars, désactivation de triton GEMM) révélant des lacunes dans le support software AMD pour hardware non datacenter
- Pas de clarté sur la scalabilité : le projet démontre une version 36.2M paramètres, mais on ne sait pas comment les techniques se généralisent aux vrais modèles DeepSeek à l'échelle production
