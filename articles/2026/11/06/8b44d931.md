## Résumé de l'article

Window Sweaters est une petite application macOS créée par Sara Gordić qui ajoute des bordures décoratives tricotées autour des fenêtres, avec des couleurs inspirées par les applications favorites de l'utilisateur pour une esthétique plus chaleureuse du bureau.

- L'application propose deux modes : « By App » (chaque application a sa propre bordure personnalisée) et « Zigzag » (bordure en zigzag uniforme avec couleurs issues des icônes des apps)
- 37 applications bénéficient de bordures personnalisées avec couleurs choisies manuellement (Apple, Microsoft Office, Slack, VS Code, Figma, Spotify, Discord, etc.) ; les autres utilisent des couleurs extraites de leurs icônes
- Installation possible via Homebrew, téléchargement du ZIP, ou via GitHub ; l'application nécessite macOS 13+, fonctionne sur Apple Silicon et Intel
- Configuration disponible depuis l'icône fil du menu bar pour modifier le style, la largeur de bordure, la taille des points, ou désactiver les bordures par application
- L'application utilise les APIs privées de macOS et s'installe dans ~/Applications ; elle est open source sous GPL-3.0

## Discussion sur Hacker News (101 commentaires)

**Avis positifs** :
- Projet créatif et amusant qui ramène de la nostalgie (comparaisons avec Kaleidoscope, WindowBlinds, xsnow), satisfaisant pour les utilisateurs qui aiment personnaliser leurs interfaces
- Démocratise la création logicielle : permet à une designer sans expertise système d'explorer une idée grâce aux LLM, ce qui n'aurait pas été possible avant
- Partage pertinent sur GitHub : c'est le bon endroit pour les projets open-source expérimentaux, même non maintenus ; la communauté en tire de la valeur et de l'inspiration pour ses propres créations
- Répond à un vrai besoin sur macOS : améliore la visibilité des fenêtres sans bordures distinctes, contrairement à Windows qui souffre du même problème
- Utilisé quotidiennement par l'auteure et continue à être amélioré ; l'engagement et la réactivité aux retours (ajout vidéo rapide) montrent une implication authentique

**Avis négatifs** :
- Risques de sécurité légitimes : nouvelles binaires d'un repo inconnu, supply chain attacks, et utiliser un agent LLM pour valider la sécurité n'élimine pas les risques réels de prompt injection
- La présentation trompeuse nuit à la crédibilité : fausse mockup IA en couverture, README généré par IA, absence initiale de vraies captures d'écran/vidéo ; difficile de discerner les choix créatifs authentiques de l'auteure
- Perte de magie créative : avant les LLM, ces projets pointaient vers le travail et la passion d'un créateur ; maintenant inondé de projets générés rapidement sans curation humaine visuelle, dilué dans du « slop »
- Instructions d'installation absurdes : proposer d'envoyer le repo à un agent IA pour installer une simple commande brew trivialise l'outil et semble contraire au pragmatisme UNIX
- Scepticisme sur la maintenabilité et les promesses implicites : risque que les utilisateurs comptent sur un support long terme d'un projet décrit comme un jouet personnel de sa créatrice
