## Résumé de l'article

Leonida est un projet de recompilation statique qui convertit le code x86-64 de la version Xbox Series de GTA 6 pour l'exécuter sur PC, en réimplémentant les logiciels système de la console et en traduisant les programmes GPU RDNA2 précompilés en SPIR-V pour Vulkan. Le projet extrait les modèles, textures et audio du jeu depuis votre propre copie du jeu et effectue tout le traitement sur votre PC sans partager les fichiers générés.

- Le projet est actuellement en phase très précoce et le jeu n'a pas encore démarré ; il attend qu'un exécutable soit disponible pour commencer le démarrage
- La construction du port se fait sur votre PC à partir de votre propre copie du jeu via un script Build.bat qui localise automatiquement le jeu et vérifie les prérequis (Python 3.12+, .NET 8 SDK, Vulkan SDK, LLVM 21+, Visual Studio 2022)
- Environ 350 GB d'espace libre est nécessaire pour les fichiers de travail, et la traduction des shaders représente l'étape la plus longue du processus de construction
- Le projet supporte Linux via Wine ou Proton pour le chargeur, avec cross-compilation possible depuis Windows
- Plusieurs options de configuration existent pour l'émulation wave64, les fallbacks GPU et la décodage audio WAV, avec un système d'enregistrement des commandes pour reprendre les compilations interrompues

## Discussion sur Hacker News (148 commentaires)

**Avis positifs** :
- La crowdsource de décompilation via LLM est une approche créative et efficace, comparable aux succès du projet Fallout New Vegas, permettant de distribuer le travail et de vérifier les résultats
- Ce projet illustre comment la piraterie force les studios à reconsidérer leurs stratégies commerciales, forçant potentiellement des lancements multi-plateforme simultanés comme l'industrie cinématographique l'a accepté
- L'utilisation d'agents IA avec des pools de tokens partagés (modèle type SETI@home) est innovante et pourrait devenir un modèle de contribution à des projets open-source complexes
- GTA 6 lancé à Q1 2027 sur PC suggère que les pressions technologiques (reverse engineering accessible) rendent obsolètes les délais de lancement exclusifs console traditionnel

**Avis négatifs** :
- Le projet repose sur des exécutables non encore disponibles/leakés et opère sur des fichiers dumped de sources non fiables, ce qui pose des questions légales fondamentales sur la violation du DMCA et la propriété intellectuelle
- Le choix de scanner récursivement le disque dur sans permission explicite de l'utilisateur est un signal d'alerte de sécurité majeur, typique du code généré par IA sans design humain approprié
- Le jeune développeur leader risque potentiellement des poursuites judiciaires massives de Take-Two, et le projet sera probablement retiré de GitHub rapidement (DMCA takedown imminence)
- L'argument du 'grudge' contre Rockstar pour justifier la piraterie ne justifie pas légalement l'accès aux fichiers leakés ; seule l'émulation homemade à partir de copies légales serait défendable
- GTA 6 est développé sur PC de base, les délais de lancement console-first relèvent de stratégie marketing (ventes multiples) plutôt que de besoins techniques réels
