## Résumé de l'article

Cloudflare, plateforme de sécurité et performance web, introduit un système de classification plus nuancé pour gérer le trafic automatisé IA selon trois catégories : Search (indexation), Agent (actions en temps réel) et Training (entraînement de modèles). Ces outils permettent aux propriétaires de sites de contrôler précisément comment les crawlers utilisent leur contenu, avec de nouveaux paramètres par défaut à partir de septembre 2026.

- Trois catégories d'utilisation IA remplacent l'approche binaire précédente (bloquer tout ou rien) : Search pour l'indexation, Agent pour les bots de chat et navigateurs, Training pour l'entraînement de modèles
- Nouvelles options de contrôle de contenu basées sur trois niveaux (immediate, reference, full) pour définir comment les bots peuvent stocker et réutiliser le contenu
- À partir du 15 septembre 2026, Training et Agent seront bloqués par défaut sur les pages avec publicités, tandis que Search restera autorisé par défaut
- BotBase, nouvelle base de données Enterprise, offre une visibilité complète et filtrable de tous les bots vérifiés avec leurs classifications et comportements
- Extension du fichier robots.txt avec un nouveau signal d'utilisation de contenu (use=immediate/reference/full) pour que les propriétaires expriment leurs préférences de manière standardisée

## Discussion sur Hacker News (127 commentaires)

**Avis positifs** :
- Cloudflare offre enfin des outils concrets pour que les propriétaires de sites contrôlent l'accès des bots IA, avec possibilité de monétisation via le programme pay-per-crawl
- Le blocage des crawlers multi-usages (Googlebot, etc.) qui mélangent indexation de recherche et entraînement IA force les géants du tech à séparer leurs usages et offre une meilleure transparence
- L'approche comportementale (que font les bots, que stockent-ils) est plus pertinente que simplement bloquer tous les bots, puisque certains bots (accessibilité, lecteurs RSS) fournissent une valeur réelle
- Ces outils répondent à un vrai problème : les crawlers IA générateurs de trafic coûteux sans retour de visite, tandis que Google menace l'équilibre de l'internet avec ses réponses IA réduisant les clics vers les sites sources

**Avis négatifs** :
- C'est un système d'honneur inefficace : il n'existe aucun moyen technique de différencier légalement un usage de search d'un usage d'entraînement IA, on ne peut pas vraiment bloquer sélectivement
- Cloudflare joue sur les deux fronts : elle vend des outils aux constructeurs d'agents IA tout en les bloquant, créant des incitations perverses où seules les agents de Cloudflare seraient traités préférentiellement
- Le programme pay-per-crawl promis reste inaccessible depuis un an (simple bouton 'demander l'accès' sans réponse), tandis que Cloudflare crée une nouvelle économie de péage sur internet
- Les décisions unilatérales de Cloudflare impactent l'intégralité du trafic internet sans consultation des parties prenantes (IETF), fragmentant potentiellement le web
- Ces blocages par défaut risquent de casser les sites par accident et constituent une concentration de pouvoir problématique : Cloudflare devient contrôleur des accès sans vrai processus démocratique
