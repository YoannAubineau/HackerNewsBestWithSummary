## Résumé de l'article

Le comité directeur de GCC a adopté une politique sur les contributions d'IA recommandée par son groupe de travail dédié. Cette politique rejette les contributions significatives sur le plan juridique (au-delà de 15 lignes) contenant ou dérivant de contenu généré par des modèles de langage, à l'exception des cas de tests générés par IA que les mainteneurs peuvent accepter.

- GCC refusera toute contribution juridiquement significative incluant ou dérivée de contenu généré par LLM, en se basant sur le seuil de 15 lignes défini par les directives GNU
- L'utilisation des LLM pour la recherche, l'analyse, la détection de bugs, la revue de code reste autorisée à condition que le résultat ne soit pas intégré aux contributions
- Les cas de test générés par IA constituent une exception et peuvent être acceptés à la discrétion des mainteneurs
- Le comité prévoit que cette politique évoluera et sera révisée régulièrement

## Discussion sur Hacker News (275 commentaires)

**Avis positifs** :
- La politique est raisonnablement équilibrée : elle autorise les LLM pour les tests, le débogage, la révision de code et les contributions mineures (≤15 lignes), tout en encadrant les contributions majeures.
- Le seuil de 15 lignes s'appuie sur des définitions juridiques établies du projet GNU, offrant une base légale cohérente plutôt qu'une interdiction arbitraire.
- Cette approche protège le projet contre les risques légaux réels : copyrights non clarifiés, code reproduit verbatim issu des données d'entraînement, et l'incertitude juridique sur la copyrightabilité du code généré par IA.
- La demande que les contributeurs comprennent et expliquent leur code maintient l'accountability humaine, ce qui était le fondement de la confiance en open source bien avant l'IA.
- La politique s'inscrit logiquement dans l'ADN du projet GNU : basé sur les libertés liées au copyright, le projet doit être prudent face à une technologie dont le statut juridique reste flou.

**Avis négatifs** :
- Le risque légal invoqué (poursuites en copyright) repose sur trois événements improbables simultanés et n'a jamais concrètement affecté un projet ; après 3-4 ans d'adoption massive, aucune poursuite n'a abouti.
- Les grands labs IA (Anthropic, Microsoft, OpenAI) offrent une indemnisation complète aux utilisateurs commerciaux, signalant leur confiance dans la non-violation ; GCC pourrait demander une couverture similaire.
- La politique décourage les contributeurs expérimentés qui utilisent les LLM de façon réfléchie et responsable, forçant au silence des correctifs de sécurité valides simplement parce qu'un outil IA a été impliqué.
- L'application est impossible à vérifier : le code généré par IA bien travaillé devient indistinguable du code humain, ce qui incitera les contributeurs à mentir plutôt qu'à être transparents.
- Cette interdiction ressemble à du rejet technologique idéologique plutôt qu'à une politique pragmatique : c'est comme interdire les compilateurs ou les linters, alors qu'outils et humains doivent coexister.
