## Résumé de l'article

Selon un rapport de sécurité, l'extension Visual Studio Claude Code d'Anthropic disponible sur Cursor contient du code malveillant. L'extension aurait la capacité de créer un accès à distance non autorisé aux ordinateurs des utilisateurs.

- L'extension officielle Claude Code pour Visual Studio sur Cursor serait compromise
- Le malware détecté agit comme un cheval de Troie d'accès à distance (RAT)
- L'analyse détaillée est disponible sur le site phorion.io

## Discussion sur Hacker News (17 commentaires)

**Avis positifs** :
- Cursor a fourni une réponse appropriée avec des instructions et scripts pour remédier à l'infection
- La découverte et la divulgation rapides d'une telle vulnérabilité dans les extensions officielles montrent que la surveillance de sécurité fonctionne
- La reconstruction de l'infrastructure de la place de marché démontre une volonté de résoudre les problèmes sous-jacents

**Avis négatifs** :
- Anthropic n'a pas fourni d'analyse des causes profondes expliquant comment la compromission s'est produite, ce qui remet en question la culture de sécurité globale
- La formulation ambiguë « cette version n'a pas été développée par Anthropic » semble détourner la responsabilité plutôt que de clarifier les faits concrets (qui a téléchargé l'extension, sous quel compte)
- L'ironie de Cursor affichant une certification de sécurité pour les agents IA juste avant cette faille soulève des questions sur la crédibilité de ces certifications
- Le manque de détails sur la source de l'intrusion (compte compromis, infrastructure Cursor elle-même) alimente les spéculations et la méfiance envers les assurances données
- Cet incident illustre une tendance plus large : les défaillances en matière de sécurité deviennent inévitables et ne feront qu'augmenter dans un écosystème d'outils IA complexe
