## Résumé de l'article

Un CNN (réseau de neurones convolutif) basé sur Inception v3, un modèle de 2015 affiné sur des images de dermatologie, a été testé contre GPT-6 Astra et Claude Fable 5.1 sur 200 lésions cutanées confirmées par biopsie. Le CNN ancien a correctement nommé le diagnostic dans 62 % des cas, contre 42 % pour les deux LLM frontières, notamment en identifiant 13 des 30 mélanomes versus 8 et 11 pour les LLM.

- Le CNN a atteint 173 diagnostiques corrects sur 200 en autorisant un second choix, contre 134 et 138 pour les LLM ; il a particulièrement surpassé les modèles sur les lésions bénignes (moles et kératoses séborrhéiques).
- Les deux LLM ont échoué de façons différentes : l'un favorisait systématiquement le carcinome basocellulaire, l'autre la kératose actinique, tandis que les erreurs du CNN sur les mélanomes le portaient à les classer comme naevus ou kératose.
- Le test utilisait MILK10k, un ensemble de données public de 2025 avec images cliniques et dermoscopiques de chaque lésion, tous les cas étant biopsies (y compris les lésions bénignes, rendant le diagnostic plus difficile).
- Le CNN, délibérément non état de l'art, était prétraîné sur des photos ordinaires puis affiné sur 68 011 images de l'archive ISIC, avec tous les cas de test exclus des données d'entraînement pour éviter la contamination.
- Le modèle est assez petit pour fonctionner directement dans un navigateur mobile via WebGPU, et les données, prompts, réponses des LLM et code de notation sont publiquement disponibles.

## Discussion sur Hacker News (169 commentaires)

**Avis positifs** :
- Les modèles spécialisés surpassent les LLM génériques pour des tâches bien définies comme le diagnostic médical, ce qui justifie l'investissement dans des architectures dédiées
- Les LLM ne devraient être utilisés que comme outils complémentaires (génération de prompts, création d'agents) plutôt que comme solutions directes pour des classifications complexes
- Ce résultat rappelle que l'engouement pour les LLM occulte l'existence d'outils éprouvés (classifieurs, XGBoost, etc.) souvent plus appropriés pour des applications ciblées
- L'article expose le problème du « hammer thinking » : les gens appliquent les LLM partout faute de connaître d'autres outils, même quand ces derniers seraient nettement supérieurs

**Avis négatifs** :
- Comparer un modèle fine-tuné sur 68 000 images dermatologiques à des LLM génériques est une comparaison déloyale ; les LLM pourraient concurrencer des modèles spécialisés s'ils étaient aussi adaptés à la tâche
- Les LLM multimodaux avec accès à des outils externes (CNN embarqué) pourraient égaler ou surpasser la performance du CNN seul, changeant complètement la conclusion
- Pour les cas d'usage sans grand volume de données ou nécessitant une adaptation rapide, les LLM offrent un meilleur rapport coût/délai que l'entraînement d'un classifieur dédié
- Le modèle CNN utilisé (Inception v3) est lui-même un architecture datée et ne représente pas l'état de l'art actuel en diagnostic dermatologique (les transformeurs d'ensemble modernes le surpassent)
