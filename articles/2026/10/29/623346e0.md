## Résumé de l'article

Claude Code est un IDE alimenté par l'IA créé par Anthropic. Depuis la version 2.1.232 (août 2026), il envoie automatiquement toutes les 30 secondes la transcription complète de chaque agent arrière-plan à son modèle (généralement Opus) pour générer un résumé de 3 à 5 mots affichant uniquement dans le panneau de statut. Cette fonctionnalité n'a pas de contrôle utilisateur et représente 18-26 % de la consommation de tokens estimée.

- Le projet Flamerix AI fournit un hook Bun précompilé (no-agent-summary.js) qui intercepte et désarme les timers responsables de ces requêtes de résumé, réduisant la consommation à zéro sans modifier le binaire.
- Les requêtes de résumé ne sont visibles que dans l'export OpenTelemetry (query_source = agent_summary) et ne figurent pas dans les journaux de session ni dans la documentation officielle sur l'utilisation des tokens en arrière-plan.
- Le hook fonctionne en enveloppant setTimeout/setInterval au niveau Bun et en reconnaissant les callbacks par leur texte source contenant un ancre spécifique ([AgentSummary]), puis en les remplaçant par un délai inerte.
- L'installation permanente nécessite de configurer la variable d'environnement BUN_OPTIONS avec le chemin absolu du preload et de redémarrer le daemon Claude Code, car celui-ci hérite de l'environnement du client qui l'a lancé.
- Une vérification après chaque mise à jour de Claude Code est recommandée car les modifications du texte source des callbacks peuvent empêcher le hook de fonctionner silencieusement.

## Discussion sur Hacker News (202 commentaires)

**Avis positifs** :
- Les appels de résumé utilisent effectivement le prompt cache, ce qui les rend moins chers que des appels standards, même si cela représente toujours une consommation significative à la fréquence de 30 secondes
- Anthropic reconnaît le problème et a déjà déployé des correctifs pour les cas les plus coûteux, tout en travaillant sur un mode moins coûteux utilisant un modèle plus petit
- Cette fonctionnalité remplit un vrai besoin : permettre aux utilisateurs et à Claude Code de suivre ce que font les agents de fond sans lire manuellement les transcriptions complètes
- Le correctif d'auto-compaction idle récemment déployé montre qu'Anthropic cherche activement à réduire les gaspillages de tokens pour les utilisateurs
- La transparence offerte par les traces OTEL a permis de détecter et d'isoler ce problème grâce au monitoring des utilisateurs

**Avis négatifs** :
- Les résumés d'agents de fond consomment 16-19% du spend total selon le rapport original, ce qui représente une part injustifiée de la facturation et était mal documenté publiquement
- Aucun paramètre officiel permettait de désactiver ces appels sans perdre les agents de fond, forçant les utilisateurs à utiliser des contournements non soutenus comme des patchs Bun
- La documentation Claude Code affirmait que les lignes de statut s'exécutaient localement sans consommer de tokens API, ce qui était techniquement inexact pour les agents de fond
- La fréquence fixe de 30 secondes ne s'adapte pas à la durée réelle de la session, pénalisant les sessions longues avec contextes volumineux et multipliant les appels inutiles
- Claude Code continue d'accumuler des fonctionnalités consommatrices de tokens (artifacts, synchronisation, plugins) sans que les utilisateurs puissent les désactiver facilement, ce qui alourdit constamment la facture
