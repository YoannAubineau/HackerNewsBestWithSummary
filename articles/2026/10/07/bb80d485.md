## Résumé de l'article

Ivan Kutskir, créateur de Photopea (éditeur photo web populaire), signale que GitHub refuse de supprimer des dépôts contenant des copies du code JavaScript de son application avec les publicités supprimées, malgré une demande DMCA envoyée il y a un mois.

- Des utilisateurs demandent à des modèles d'IA d'extraire le code JavaScript de Photopea.com, de retirer les publicités, et publient le résultat sur GitHub à titre de nouveau produit
- Plusieurs dizaines de tels dépôts existent actuellement, fragmentant la base utilisateurs et endomageant la réputation du développeur
- GitHub a rejeté la demande DMCA en arguant que le contenu ne violerait pas le 17 U.S. Code § 1201 (dispositions anti-contournement)
- Le développeur remet en question l'efficacité du processus et l'absence apparente d'examen humain des signalements
- Il envisage de consulter un avocat pour explorer des voies légales externes

## Discussion sur Hacker News (197 commentaires)

**Avis positifs** :
- GitHub devrait respecter les procédures DMCA légales et retirer le contenu rapidement sans tenter de vérifier les violations, la responsabilité légale étant établie par le processus judiciaire
- Ivan a consacré plus d'une décennie à développer un code complexe et hautement spécialisé ; le vol de propriété intellectuelle est réel et devrait être pris au sérieux par les plateformes
- Le recours à un avocat spécialisé en droit d'auteur est la solution la plus viable pour contrer cette violation persistante et obtenir des dommages
- Photopea est devenu une cible valuable justement parce qu'il fournit une réelle valeur ; les copies malveillantes nuisent à la réputation et au support utilisateur

**Avis négatifs** :
- Distribuer du code JavaScript côté client revient à rendre public le code source ; les modèles commerciaux dépendant du secret du code sont fondamentalement fragiles sur le web
- Les LLM peuvent désormais reproduire une fonctionnalité identique à partir des sorties observables sans accéder au code source, rendant les takedowns DMCA obsolètes
- Le modèle publicitaire suscite lui-même de la frustration chez les utilisateurs, ce qui crée une demande pour des versions sans publicité et justifie partiellement les copies
- Photopea lui-même reproduit largement l'interface et la fonctionnalité de Photoshop ; le projet n'est pas exempt de critique éthique concernant l'appropriation d'idées existantes
- Le droit d'auteur appliqué au logiciel est conceptuellement problématique et historiquement contesté ; les forks et copies sont une réalité inévitable de l'informatique open web
