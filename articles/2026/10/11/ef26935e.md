## Résumé de l'article

DuckDB 2.0, en alpha et prévue pour l'automne, introduit trois améliorations majeures qui accélèrent les requêtes sans modification de code. DuckDB est un moteur de base de données analytique intégrable, léger et orienté colonne.

- L'async I/O sépare les téléchargements réseau des décodages CPU, multipliant par 2 à 3 la vitesse de lecture S3 grâce à un pool de threads dédié qui récupère les row groups en amont (read_ahead_depth = -1 par défaut)
- Les requêtes CTE récursives réécrits lisent la table une seule fois et construisent un index unique au lieu de relire la table à chaque niveau, offrant des gains de 40x sur les chaînes parent/enfant profondes (historique git, lignage de données, filetages de réponses)
- Le type VARIANT en première classe, avec shredding, extrait les champs JSON cohérents dans des colonnes réelles tandis que les champs incohérents restent binaires, réduisant le stockage de 2,7x et accélérant les requêtes de 6x par rapport à JSON texte
- Les fonctionnalités supplémentaires incluent les triggers, les schémas imbriqués, les DML dans les CTE, un mode de compatibilité Spark et le cache de fichiers distant avec spill sur disque
- L'installation de l'alpha est disponible en une ligne de commande ; MotherDuck supportera 2.0 à proximité de la sortie officielle
