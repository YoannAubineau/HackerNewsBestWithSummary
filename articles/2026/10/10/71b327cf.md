## Résumé de l'article

Bitwarden, gestionnaire de mots de passe open source, introduit un modèle de double licence : les applications distribuées via les stores utiliseront une licence commerciale, tandis que le code GPLv3 reste accessible sur GitHub. L'entreprise affirme maintenir son engagement envers l'open source, l'auto-hébergement et un plan gratuit permanent, mais cette transition suscite des inquiétudes dans la communauté.

- Les applications commerciales et OSS restent basées sur le même code source disponible sur GitHub, qui continue d'être auditable et modifiable
- Certaines nouvelles fonctionnalités futures seront développées uniquement sous licence commerciale, d'autres seront évaluées au cas par cas
- L'auto-hébergement n'est pas affecté pour les utilisateurs ; le changement de licence cible les entreprises repackageant et revendant Bitwarden
- La communauté exprime des craintes quant à une possible dégradation progressive vers un modèle fermé, citant des précédents comme MinIO et CoinKite
- Bitwarden maintient que le code GPLv3 continuera à être développé et que l'accès public au code source n'est pas modifié

## Discussion sur Hacker News (207 commentaires)

**Avis positifs** :
- Le changement de licence est compréhensible étant donné le besoin de monétiser et de se protéger contre les copies commerciales non autorisées, similaire aux défis rencontrés par Redis et Elasticsearch
- Bitwarden reste accessible en auto-hébergement via Vaultwarden et continue de publier le code source, ce qui offre une meilleure protection que les alternatives entièrement propriétaires
- Le modèle source disponible avec restrictions commerciales reste acceptable pour les utilisateurs payants et les auto-hébergeurs, tant que le code reste accessible et auditable
- Le produit reste excellent et mérite le soutien financier ; les clients premium reconnaissent la valeur apportée et acceptent les augmentations tarifaires raisonnables

**Avis négatifs** :
- C'est une application typique de la stratégie 'faire bouillir la grenouille' : changements graduels, hausse tarifaire (doublement du prix annuel passant de 10$ à 19,80$), et futures fonctionnalités sous licence commerciale uniquement
- Le changement intervient après l'arrivée du private equity, levant des doutes sur l'intention réelle de maintenir l'open source à long terme et rappelant les cas de Redis et OpenSolaris
- Les applications clientes Bitwarden (bureau et mobile) sont lourdes, lentes et mal conçues comparées aux alternatives ; Keyguard et d'autres clients tiers offrent de meilleures performances
- L'auto-hébergement deviendra non viable si Bitwarden casse délibérément la compatibilité avec Vaultwarden ou si les applications clientes officielles cessent de fonctionner avec les serveurs auto-hébergés
- Nombreux utilisateurs ayant fondé leur confiance sur l'engagement open source original se sentent trahis ; l'absence de justification claire du changement aggrave le manque de transparence
