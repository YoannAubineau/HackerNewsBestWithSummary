## Résumé de l'article

Kagi, éditeur d'un navigateur WebKit indépendant appelé Orion, abandonne le développement de ses versions Linux et Windows pour concentrer ses ressources limitées sur les versions macOS et iOS. L'entreprise rendra le code source public afin que la communauté puisse poursuivre ces projets.

- La bêta Linux continuera de fonctionner jusqu'au 2 octobre 2026 sans nouvelles mises à jour ; le lancement Windows prévu fin 2026 n'aura pas lieu
- Kagi, petite équipe de quelques développeurs financée par ses utilisateurs, juge que construire un navigateur multiplateforme dépasse ses capacités
- Le code source sera libéré dans les 30 prochains jours ; Kagi travaille avec des fondations open-source pour assurer une gouvernance à long terme
- Les versions macOS et iOS d'Orion bénéficieront de toutes les ressources libérées, avec des améliorations attendues dans les mois à venir
- Kagi invite développeurs et organisations à reprendre les projets Linux et Windows via support@kagi.com

## Discussion sur Hacker News (115 commentaires)

**Avis positifs** :
- Open-sourcing Orion pour Linux et Windows permet à la communauté de continuer le développement et offre une opportunité pour d'autres de reprendre le projet
- Cette décision permet à Kagi de se concentrer sur son cœur de métier (le moteur de recherche) plutôt que de disperser ses ressources limitées sur plusieurs produits
- La diversité des moteurs de rendu est importante pour éviter la domination de Chromium ; Orion sur macOS continuant à utiliser WebKit contribue à cette diversité
- Orion remplit une niche utile sur iOS et macOS, notamment pour les utilisateurs souhaitant des extensions, un adblocking natif, et une meilleure intégration à l'écosystème Apple

**Avis négatifs** :
- Ne pas open-sourcer la version macOS crée une fragmentation problématique : les versions Linux/Windows divergeront du code macOS, rendant la maintenance future quasi impossible
- Le navigateur n'a jamais eu de véritable utilité clairement définie, occupant mal la place entre Safari, Firefox et d'autres alternatives existantes
- Pour les utilisateurs Linux, un navigateur propriétaire propriétaire est un obstacle majeur ; la majorité préfère des solutions open-source comme Firefox ou Brave
- L'abandon simultané du produit et son ouverture démotive les contributeurs potentiels, créant un signal faible qui réduit les chances de succès communautaire
- Kagi a dilué ses efforts en se lançant dans trop de domaines à la fois ; plusieurs utilisateurs signalent une dégradation de la qualité du service de recherche principal
