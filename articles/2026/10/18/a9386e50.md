## Discussion sur Hacker News (193 commentaires)

**Avis positifs** :
- OpenGL sur macOS fonctionne via une couche Metal avec extensions propriétaires, rendant les solutions alternatives (Vulkan conformant 1.4, wgpu) viables pour les développeurs
- C'est un problème de version candidate (RC) non encore publiée, ce qui est normal lors du développement ; les RC servent justement à attraper ces bugs avant la sortie officielle
- Un ingénieur Apple a reconnu le bug, assigné un numéro de ticket et demandé des retests, ce qui montre que le problème est bien pris en charge dans le processus de triage interne
- Le rapport de bug est techniquement excellent avec un cas de reproduction minimal clair, facilitant le dépannage rapide

**Avis négatifs** :
- Apple demande au reporter de continuer à tester lui-même à chaque nouvelle build sans transparence sur la timeline ou les progrès, ce qui est un fardeau inéquitable pour les bénévoles
- Absence de test de régression interne sur OpenGL malgré l'existence d'APIs communes multiplateforme montre une négligence dans l'assurance qualité
- La dépréciation d'OpenGL en 2018 et le manque de support réel pour les alternatives universelles (Metal étant fermé à Apple) a fragmenté l'écosystème des développeurs
- Cet incident s'inscrit dans un pattern plus large de régressions logicielles non rattrapées (audio cassé, Bluetooth bugué, window manager dysfonctionnel) affectant même les versions stables depuis des mois ou des années
