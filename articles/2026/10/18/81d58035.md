## Résumé de l'article

Pele est un outil qui convertit la syntaxe Mermaid en diagrammes SVG personnalisables par CSS. Il permet de modifier couleurs et polices via des variables CSS sans nécessiter un re-rendu du diagramme.

- Accepte la syntaxe Mermaid standard en entrée et génère du SVG optimisé pour l'intégration web
- Utilise des variables CSS pour contrôler l'apparence (couleurs de fond, texte, bordures, surfaces), appliquées dynamiquement sans re-rendu
- S'intègre dans les applications via une API simple : passer la syntaxe Mermaid à la fonction render() qui retourne le SVG à insérer dans la page
- Supporte les mêmes types de diagrammes que Mermaid et inclut une documentation de compatibilité

## Discussion sur Hacker News (26 commentaires)

**Avis positifs** :
- Pele répond à un vrai besoin : permettre le rendu de diagrammes Mermaid sans environnement navigateur complet, utile pour l'intégration dans des pipelines CI/CD et la génération de documentation
- La qualité de la mise en page des diagrammes est impressionnante comparée à Mermaid standard, qui produit souvent des connexions mal organisées et croisées
- Excellent pour la version control et l'intégration avec des outils IA : les diagrammes restent en markdown, éditables et synchronisables
- La philosophie de Pele (suivre la syntaxe Mermaid sans imposer sa mise en page) offre une alternative flexible et pragmatique aux frustrations de layout de Mermaid

**Avis négatifs** :
- Le layout des graphes reste un problème fondamental complexe ; simplement améliorer le styling ne résout pas les enjeux topologiques sous-jacents
- La preview Mermaid dans le playground est cassée pour certains utilisateurs, indiquant des problèmes de compatibilité ou de stabilité
- L'accessibilité en mode sombre est insuffisante : les exemples ne sont pas assez contrastés pour la lecture nocturne
- Absence visible de lien GitHub sur la page principale rend difficile la découverte du code open source et le partage du projet
