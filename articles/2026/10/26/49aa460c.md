## Résumé de l'article

PaperPilot est une boîte à outils PDF et documents écrite en Rust pur, qui s'exécute localement sans cloud, Chromium ni dépendances externes. Elle propose une interface CLI, un serveur MCP (Model Context Protocol) pour agents IA, une API REST, une version navigateur WASM et une application de bureau Tauri, partageant tous le même noyau Rust pour une cohérence garantie.

- Fonctionnalités actuelles : fusion et compression de PDF, rotation de pages, extraction de texte, OCR, détection PII, watermarking, validation de signatures, et conversion Excel vers JSON/CSV
- Intégration agents IA : supporte Codex, Claude Code, Kimi Code et Pi via protocole MCP pour des opérations PDF directes dans les agents
- Confidentialité absolue : aucun fichier ne quitte la machine, vérifiable par inspection de l'onglet réseau du navigateur
- Feuille de route publique : conversion PDF ↔ Markdown/HTML/JSON en v0.7, export vers Word/Excel/PowerPoint en v0.8, chiffrement et signature en v0.9
- Licence Community Edition en Apache 2.0 ; version Enterprise avec SSO, RBAC et audit logs disponible séparément

## Discussion sur Hacker News (77 commentaires)

**Avis positifs** :
- L'approche multi-interfaces (CLI, desktop natif, WASM, API REST, MCP) offre une flexibilité réelle pour différents cas d'usage, notamment en navigateur sans installation
- Le focus sur la confidentialité (zéro cloud, traitement local) répond à un besoin légitime pour les documents sensibles (formulaires fiscaux, contrats juridiques, dossiers médicaux)
- L'intégration MCP avec les agents IA locaux (Claude Desktop, Cursor) ouvre des possibilités innovantes d'automatisation sans envoi vers le cloud
- Les performances rapides (20-130ms) et la licence Apache 2.0 open-source constituent des avantages concrets
- L'interface WASM en navigateur démocratise l'accès sans nécessiter ligne de commande ou installation, utile sur téléphones d'amis ou ordinateurs partagés

**Avis négatifs** :
- Réinvention problématique : la communauté Rust dispose déjà de solutions matures comme printpdf (MIT, WASM, années de correctifs edge-cases) et d'autres bibliothèques; recoder complètement augmente la dette technique sans bénéfice
- Risques de sécurité : les multiples PDF vibe-codés créent autant de nouvelles surfaces d'attaque; les CVE PDF existants restent non adressés par manque de bataille-testing
- Doutes sur l'authenticité et la génération : le texte ressemble fortement à de la sortie LLM; les mentions de MuPDF (même en notes d'architecture) suggèrent une dérivation minimalement disclosed
- Terme trompeur : l'app Tauri/Svelte n'est pas 'native' (juste un navigateur Chromium packagé); ce langage marketing trompe les utilisateurs
- Manque de recherche préalable : aucune mention de solutions existantes (printpdf, pdf_oxide, Bento PDF, presse, etc.) dans la présentation; ignorance apparente du paysage existant
