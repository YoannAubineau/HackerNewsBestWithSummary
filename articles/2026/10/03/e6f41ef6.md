## Discussion sur Hacker News (83 commentaires)

**Avis positifs** :
- ds4 offre des performances exceptionnelles optimisées pour du matériel grand public spécifique (MacBook M5 Max, Intel Ultra, Ryzen AI), avec rapports de 22-100+ tokens par seconde et support natif du Metal sur Apple Silicon
- Approche minimaliste et philosophie de dépendances minimales (héritée de Redis) : se concentre sur un ensemble limité de modèles soigneusement choisis qu'il optimise réellement au lieu de tenter de supporter tous les modèles génériquement
- Excellente qualité de quantification, support de longues fenêtres de contexte (1M tokens), streaming SSD pour faire tourner de très grands modèles sur du matériel limité, et des améliorations continues (vision, support Qwen, outils d'agent)
- Pertinence accrue de l'inférence locale : les modèles DeepSeek/Qwen sont maintenant assez capables pour des usages sérieux (tool calling, thinking, agentic workflows) sur du matériel grand public, rendant l'alternative cloud moins nécessaire
- Conception fondée sur les LLM : antirez a délibérément choisi C pour sa compatibilité supérieure avec les données d'entraînement des LLMs (massive base de code C de qualité), permettant une meilleure génération de code par les modèles que Rust

**Avis négatifs** :
- Positionnement flou : ds4 ne semble pas fondamentalement différent de llama.cpp ou Ollama existants, mais plutôt une variante optimisée pour des modèles/hardware spécifiques plutôt qu'une innovation paradigmatique
- Ressources matérielles élevées : même si présenté pour du matériel 'grand public', 96-128 GB de RAM (ou SSD streaming) reste inaccessible pour la plupart des utilisateurs ; les modèles denses locaux ne peuvent rivaliser avec les modèles frontière cloud en fiabilité et intelligence
- Site de présentation critiqué comme du 'slop marketing' avec animations inutiles et jargon vide (le repo GitHub et le blog d'antirez sont plus clairs), donnant l'impression que c'est AI-généré plutôt que authentique
- Antécédent critique : antirez historiquement méprisé pour ses choix d'ingénierie sur Redis (protocoles maison plutôt que Raft standard), levant des questions sur sa capacité à prendre des décisions d'architecture fondamentales correctement
