## Résumé de l'article

Web Search API est une nouvelle API en version bêta proposée par Cloudflare qui permet aux applications et agents IA de rechercher sur Internet et d'ancrer leurs réponses dans des informations actualisées, plutôt que de s'appuyer sur des données d'entraînement obsolètes. L'API fonctionne via AI Gateway et offre le choix entre trois fournisseurs de recherche.

- Trois fournisseurs de recherche disponibles au lancement : Ceramic.ai, Exa et Linkup, tous engagés dans la rétention zéro des données et les normes de crawling de bots vérifiés de Cloudflare
- Les requêtes de recherche sont traitées via AI Gateway, apparaissent dans les logs de passerelle et sont facturées au prix de l'API publié de chaque fournisseur, sans surcoût additionnel
- Les utilisateurs peuvent intégrer l'API via REST ou depuis un Worker avec le binding AI
- Option pour apporter sa propre clé API de fournisseur

## Discussion sur Hacker News (219 commentaires)

**Avis positifs** :
- Intégration simplifiée pour les clients utilisant déjà Cloudflare : un seul fournisseur, une facturation centralisée, pas de processus d'approvisionnement supplémentaire, et failover automatique entre les trois fournisseurs
- Utilité pour les systèmes d'agents IA : permet aux agents exécutés sur Cloudflare Workers d'accéder facilement à la recherche web sans dépendre d'une API Google fermée
- Alternative aux API de recherche fermées : Google et Bing ont discontinué leurs API de recherche officielles, créant une demande pour des alternatives comme celle-ci
- Commodité opérationnelle : certains clients préfèrent consolider tous les services chez un seul fournisseur cloud (AWS/Azure/GCP), et Cloudflare reproduit cette stratégie
- Outils de gestion centralisés : possibilité de gérer les limites de budget, les limites de débit et les clés API via une interface unique plutôt que de maintenant plusieurs proxies

**Avis négatifs** :
- Problème de verrous anti-concurrentiels : Cloudflare bloque les bots mais offre accès aux fournisseurs vérifiés partenaires, créant un système de gardiens à deux niveaux potentiellement abusif
- Qualité incohérente des résultats : plusieurs utilisateurs rapportent des résultats de recherche non pertinents ou incomplets comparé à Google/DuckDuckGo, avec des problèmes d'indexation (absence de résultats pour le propre site du fournisseur)
- Couche d'indirection inutile : Cloudflare joue un simple rôle de routeur/proxy sans valeur ajoutée réelle comparé à l'utilisation directe des fournisseurs, avec latence supplémentaire
- Préoccupations de confiance : Cloudflare est dans la position du homme-du-milieu pour toutes les données, avec des antécédents documentés de résiliation de comptes clients sans avertissement et de demandes d'upgrade forcées
- Ambiguïté contractuelle problématique : les conditions d'utilisation interdisent le stockage/la mise en cache des résultats avec des formulations vagues comme « raisonnablement nécessaire », créant une incertitude juridique pour les développeurs
