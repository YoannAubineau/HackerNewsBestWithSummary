## Résumé de l'article

Mistral a déposé un brevet pour une méthode permettant aux modèles de langage de générer du code qui encapsule et exécute des appels d'outils de manière structurée. Cette approche améliore la façon dont les LLM interagissent avec des services externes en utilisant le code comme intermédiaire.

- Le LLM génère un bloc de code en langage de programmation qui encapsule les appels d'outils demandés par l'utilisateur
- Le serveur exécute ce bloc de code dans un environnement sécurisé (sandbox)
- Lors d'un appel d'outil en attente, l'exécution est mise en pause et l'appel est transmis au client
- Les résultats du client sont réintégrés dans le bloc de code et son exécution reprend
- Le résultat final du code exécuté est retourné au LLM pour traitement

## Discussion sur Hacker News (150 commentaires)

**Avis positifs** :
- Le concept d'une IA générant et exécutant elle-même des appels de fonction est une amélioration notable par rapport aux systèmes RPC traditionnels, distinguant cette approche des technos existantes.
- Les commentaires reconnaissent que Mistral, bien que dotée de 20 milliards de dollars, reste un acteur mineur face aux géants (OpenAI, Anthropic, Google), justifiant un besoin de défense par les brevets.
- Les brevets logiciels servent légitimement de guerre défensive : accumuler un portefeuille de brevets permet d'éviter les poursuites en contre-attaquant par des brevets concurrents.

**Avis négatifs** :
- Des précédents directs existent : CodeAct (arxiv 2402.01030) et les implémentations Anthropic/OpenAI l'ont déjà démontré; Cloudflare Code Mode date d'avant le dépôt (septembre 2025 vs mars 2026); c'est du simple RPC/IPC rebaptisé 'IA'.
- L'innovation est triviale et évidente : des appels de fonction asynchrones sur réseau ne méritent pas de brevet; tout développeur les implémente régulièrement sans y penser.
- Le système des brevets logiciels aux USA est intrinsèquement corrompu : l'USPTO monétise les dépôts sans vérifier la validité, les examens sont superficiels, et les mauvais brevets se multiplient; seuls les riches peuvent les contester en justice.
- Cette stratégie est typique du jeu monopolistique : des entreprises génèrent massivement des brevets de faible qualité pour créer des obstacles juridiques contre les petits concurrents, sans aucune valeur technologique réelle.
- Contraste ironique : un brevet sur une 'invention' pratiquement impossible à breveter en Europe, déposé aux USA uniquement pour des raisons commerciales et de protection contre les contrefaçons—les vrais motifs n'ont rien à voir avec l'innovation.
