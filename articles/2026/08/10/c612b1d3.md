## Résumé de l'article

Un jeu de mystère criminel utilise la reconnaissance vocale pour permettre au joueur d'interroger des suspects virtuels en conversant naturellement. Le joueur doit identifier les contradictions dans leurs alibis et trouver le coupable.

- Le gameplay repose sur des interviews vocales naturelles avec des suspects IA
- Le joueur doit détecter les incohérences et les mensonges dans les témoignages
- Le jeu propose une démonstration fonctionnelle du concept

## Discussion sur Hacker News (76 commentaires)

**Avis positifs** :
- Le concept de mystère interactif avec interaction vocale représente une avancée intéressante pour les jeux d'aventure et de narration, longtemps rêvée par les créateurs de jeux
- L'expérience immersive fonctionne bien dans sa forme actuelle et garde les joueurs engagés malgré les défauts potentiels ; l'interaction fluide entre suspects permet une progression rapide et naturelle
- Le projet combine intelligemment les LLM avec une base de connaissances partagée pour maintenir la cohérence narrative et éviter les hallucinations des personnages
- C'est un cas d'usage honnête et transparent de l'IA générative, clairement présenté comme tel, avec le développeur en communication active sur les limitations techniques et les coûts

**Avis négatifs** :
- Les voix générées par IA restent peu convaincantes pour de nombreux utilisateurs ; des voix humaines ou amateurs seraient préférables à la narration automatisée
- Problème de sécurité critique : exposition de la clé API OpenAI en clair dans le code JavaScript, permettant à quiconque d'utiliser le token à des fins malveillantes
- L'exigence de créer un compte rebute les utilisateurs qui refusent les comptes supplémentaires ; les données vocales sont envoyées à OpenAI et pourraient être utilisées pour l'entraînement
- Le jeu souffre d'immersion brisée lors des accusations (validation formelle interrompant le roleplay) et de manque de contexte temporel cohérent entre interactions avec les suspects
- Les coûts OpenAI non gérés causent des pannes répétées du service ; le modèle économique n'est pas durable sans monétisation ou alternatives moins coûteuses (modèles locaux plus légers)
