## Résumé de l'article

Bonsai est une bibliothèque UI pour construire des applications web performantes et réactives en OCaml, inspirée par Elm et utilisée pour presque tous les outils web internes de Jane Street. Elle se distingue en séparant l'état, l'incrémentalité et le rendu, permettant une composition modulaire et une optimisation des calculs sur chaque valeur, pas seulement le rendu visuel.

- Les composants Bonsai sont des machines à états purement fonctionnelles et composables, avec un système de rendu incrémental qui évite les recalculs inutiles
- La gestion d'état n'est pas liée aux composants explicites, offrant une API étendue pour gérer le cycle de vie et la portée de l'état sans remontée manuelle à la racine de l'application
- Utiliser OCaml sur le frontend et backend permet de partager le même langage et système de types, simplifiant la maintenabilité des grandes bases de code et la portabilité des systèmes textuels existants vers le web
- Bonsai inclut un langage de templating, des feuilles de style spécifiques aux composants, et un système de tests automatisés complet permettant de tester les composants par manipulation programmatique du DOM
- La suite complète comprend Bonsai (machines à état incrémentales génériques), Bonsai_web (interfaces web interactives) et Bonsai_term (interfaces terminal interactives)

## Discussion sur Hacker News (94 commentaires)

**Avis positifs** :
- Bonsai offre un vrai avantage : utiliser le même langage et les mêmes types OCaml côté frontend et backend, avec aussi une implémentation terminal (Bonsai_term) bien fonctionnelle
- Le framework excelle pour les cas d'usage spécialisés : applications de trading et fintech qui nécessitent une haute densité informationnelle, des interfaces denses et une réactivité optimale pour les utilisateurs professionnels
- L'architecture sous-jacente est élégante : les développeurs apprécient le modèle de programmation fondé sur des machines à états incrémentales et composables, avec un système de types strict qui évite les erreurs
- Jane Street dispose des ressources pour maintenir et polir ce framework à long terme, sans être limité par les problèmes classiques de compilation, hot-reload ou bus factor que rencontrent les petits projets

**Avis négatifs** :
- Bonsai arrive trop tard : les frameworks UI modernes et l'assistance IA rendent les nouveaux frameworks UI largement obsolètes; on peut générer du code frontend bespoke en une requête
- L'intégration à l'écosystème JavaScript est très limitée : impossible d'utiliser facilement React, GraphQL et les outils JS standards, contrairement à d'autres tentatives comme Melange ou ScalaJS
- Les interfaces générées par Bonsai paraissent très datées et peu polies : esthétique des années 1990 avec une lisibilité compromise par l'absence d'espaces, bien que cela soit volontaire pour les traders
- L'adoption reste très niche et risquée : dépendre d'un framework OCaml obscur créé en interne par une seule entreprise pose des questions de maintenabilité, d'évolution future et d'expertise disponible sur le marché
