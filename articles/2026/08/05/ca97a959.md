## Résumé de l'article

Adform, un géant de la publicité en ligne servant 1,5 milliard d'annonces quotidiennes, a été compromis le 27 juillet avec du code malveillant intégré dans ses annonces. Le code malveillant remplaçait les adresses de portefeuille cryptographique dans le presse-papiers des victimes toutes les trois secondes, forçant les utilisateurs à envoyer leurs cryptomonnaies à des adresses contrôlées par le pirate informatique.

- Le chercheur en sécurité Kevin Beaumont a révélé que du code utilisé pour charger les publicités Adform sur les sites clients a été modifié de manière malveillante
- Le malware compromettait les appareils des utilisateurs visitant des sites utilisant les services Adform, sans que le site lui-même soit responsable
- Adform enquête toujours pour déterminer si les pirates ont accédé à des données sur les sites visités par les utilisateurs
- L'entreprise n'a pas divulgué comment elle a été compromise initialement ni le nombre de personnes affectées
- Cet incident illustre pourquoi les bloqueurs de publicités sont essentiels : ils auraient empêché le chargement du code malveillant

## Discussion sur Hacker News (100 commentaires)

**Avis positifs** :
- Les piratages de réseaux publicitaires (comme Adform) et les malwares distribués via les ads démontrent que les ad-blockers sont nécessaires pour la sécurité, au-delà du simple confort de suppression des annonces
- Les ads modernes du web exécutent du code JavaScript arbitraire de tiers, contrairement aux simples bannières des années 90, ce qui les rend intrinsèquement malveillantes et capables de compromette les appareils
- Les sites bombardent les utilisateurs de pop-ups, slide-ins et autres tactiques irritantes qui dégradent volontairement l'expérience utilisateur pour forcer la monétisation publicitaire
- Le modèle actuel basé sur l'exploitation de l'attention via le suivi intensif et les contenus dopaminergiques addictifs crée un environnement numérique exploitateur et irresponsable
- Les réseaux publicitaires manquent complètement de responsabilité : aucune conséquence réelle pour les consommateurs infectés par des malwares distribués via leurs plateformes

**Avis négatifs** :
- Le piratage d'Adform ne justifie pas d'ad-blockers ; le problème réel est une meilleure sécurité navigateur, pas l'absence d'ads — c'est confondre le symptôme avec la cause
- Internet moderne repose sur des services gratuits financés par la publicité ; sans ads, beaucoup de sites disparaîtraient ou passeraient à des modèles payants créant un internet fragmenté par classe sociale
- L'argument que les ads augmentent les prix est économiquement faible : les prix sont fixés par le marché, pas par les profits des annonceurs ; supprimer la pub ne garantirait pas des prix plus bas
- Les ads ne sont intrinsèquement pas mauvaises ; la population restreint simplement volontairement des contenus utiles au lieu de choisir où trouver des informations (comme des annuaires classiques)
- Le réseau publicitaire fournit une structure progressiste où attention égale opportunité (tous ont 24h/jour) ; les alternatives (paywalls, abonnements) seraient plus inégalitaires que le modèle actuel
