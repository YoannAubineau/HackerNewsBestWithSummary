## Discussion sur Hacker News (144 commentaires)

**Avis positifs** :
- Le projet offre une interface intéressante et une présentation attrayante des données financières, même s'il ne prétend pas concurrencer Bloomberg
- C'est un projet open source auditable sous licence MIT, gratuit d'accès, avec le code source accessible et les binaires compilés disponibles
- L'agrégation de données publiques (Yahoo, SEC) et la présentation visuelle peuvent être utiles pour remplacer plusieurs onglets de navigateur
- Le développeur partage proactivement son travail avec la communauté plutôt que de le garder pour lui seul

**Avis négatifs** :
- La source de données (Yahoo Finance et SEC) est limitée pour l'historique ; les données financières de qualité professionnelle nécessitent des abonnements payants (~30k$/an) que ce projet ne peut pas égaler
- La véritable valeur de Bloomberg réside dans le chat de trading (où ~90% du volume des obligations mondiales est négocié), l'effet réseau avec les professionnels, et l'exhaustivité des données — éléments impossibles à reproduire
- Les problèmes techniques du site (boutons de téléchargement incohérents, documentation 404, rupture d'affichage) soulèvent des questions sur la qualité générale du produit et réduisent la confiance pour une adoption professionnelle
- L'utilisation apparente d'outils AI/LLM pour vibe-coding crée une perception que le projet manque de soin et suscite des préoccupations de sécurité et de qualité, particulièrement pour traiter des données sensibles
