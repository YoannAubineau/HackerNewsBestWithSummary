## Résumé de l'article

Donkey.bas est un jeu vidéo classique écrit en 1981 par Bill Gates et Neil Konzen pour IBM PC DOS. Ce programme de 131 lignes servait de démonstration des capacités graphiques et sonores de BASICA, le dialecte BASIC de l'époque.

- Le jeu, où le joueur doit éviter un donkey en changeant de voie, est devenu un exemple historique du premier logiciel grand public compatible IBM PC
- Initialement livré avec les versions précoces de DOS (version 1.10 publiée en 1982), il illustrait les possibilités du mode graphique CGA
- Une recréation JavaScript moderne reproduit le gameplay original en conservant l'esprit du titre des années 1980

## Discussion sur Hacker News (125 commentaires)

**Avis positifs** :
- DONKEY.BAS et les jeux BASIC compagnons (GORILLAS, NIBBLES) représentent une époque remarquable où apprendre à programmer était accessible et amusant pour les enfants, sans dépendances complexes ni barrières à l'entrée.
- Le caractère compact du code (131 lignes) montre l'élégance et la complétude des anciens environnements BASIC intégrés, qui auraient difficilement pu être reproduits en C ou SDL moderne sans beaucoup plus de lignes.
- Ces jeux étaient des « gateway drugs » pour la programmation : modifier le code source était une expérience éducative naturelle et gratifiante permettant de découvrir comment les systèmes fonctionnaient.
- La nostalgie pour cette ère reflète une perte réelle : la disparition d'un écosystème simple, auto-contenu et transparent où on pouvait comprendre la pile technologique entière sans expertise approfondie.
- L'émulation complète de QuickBASIC en navigateur avec virtualisation CPU, VGA et interrupts représente un effort extraordinaire de préservation culturelle technologique.

**Avis négatifs** :
- Le port en navigateur n'est pas particulièrement novateur (plusieurs ports et versions web existaient déjà avant celui-ci), et le projet pose des questions sur sa véritable originalité.
- La détection de collision du jeu original était buggée, enregistrant des collisions même si la voiture avait dépassé le donkey, un défaut hérité que les adaptations modernes ne corrigent pas nécessairement.
- Les effets sonores du port sont anachroniques : les premiers IBM ne disposaient que de haut-parleurs magnétiques très basiques, tandis que les versions modernes les sur-sophistiquent.
- La comparaison entre BASIC et les outils modernes est biaisée : SDL n'est pas conçu pour être utilisé directement (40 lignes suffisent pour une fenêtre basique), et le code BASIC compresse artificiellement les lignes avec plusieurs instructions pour gonfler le contraste.
- Bien que nostalgique, BASIC était un langage médiocre avec des pratiques terribles (numérotation des lignes, variables globales massives) ; la vraie perte n'est pas le langage lui-même mais la simplicité pédagogique et la transparence du système.
