## Résumé de l'article

Cursor, un éditeur de code assisté par IA, a retiré l'affichage des montants en dollars de sa page d'utilisation pour les plans individuels et d'équipe, les remplaçant par des comptages de tokens. Ce changement, appliqué le 31 juillet 2026, affecte également les données historiques accessibles via l'API.

- Le changement est intentionnel : les montants en dollars ne sont plus affichés sur la page d'utilisation ni retournés par l'endpoint API pour les plans non-entreprise, seuls les tokens sont visibles
- L'équipe Cursor justifie cette décision en expliquant que les montants affichés en dollars causaient de la confusion (ils étaient souvent plus élevés que le coût réel du plan en raison des crédits inclus) ; seule l'utilisation à la demande payante conserve un affichage en dollars
- Les utilisateurs expriment leur frustration : ils utilisaient le suivi des coûts en dollars plusieurs fois par jour pour gérer les budgets, comparer l'efficacité des modèles IA, et suivre les dépenses par utilisateur dans les plans d'équipe
- Les données de coût à la demande restent accessibles dans le tableau de bord (Dashboard > Spending) et dans les exports CSV, mais de nombreux utilisateurs considèrent ces solutions moins pratiques que le graphique en dollars supprimé
- Les utilisateurs demandent le rétablissement de la fonctionnalité ou au minimum un bouton de basculement pour revenir à l'affichage en dollars, citant des problèmes de transparence et la nécessité de suivre les coûts réels facturés

## Discussion sur Hacker News (80 commentaires)

**Avis positifs** :
- Cursor offre une meilleure intégration IDE et une expérience sans friction comparée aux alternatives (extensions VS Code, Claude Code, etc.), particulièrement pour l'édition manuelle et la revue approfondie du code
- Composer 2.5 est reconnu comme un modèle d'agent supérieur qui produit du code de meilleure qualité que Claude Code pour les mêmes prompts
- La capacité à basculer entre plusieurs modèles (Anthropic, OpenAI, xAI, Kimi, GLM) directement dans l'interface offre une flexibilité unique pour valider et comparer les résultats

**Avis négatifs** :
- Retirer les informations de coût de l'interface est clairement hostile aux utilisateurs et rend impossible le suivi de la consommation réelle sans effort administratif excessif
- Le prix de $20/mois est devenu non compétitif face à Claude Code et Codex, particulièrement pour ceux qui utilisent déjà des abonnements Anthropic ou OpenAI
- Les changements récents dégradent l'expérience d'édition manuelle du code et font perdre à Cursor son avantage de fork VS Code simple à utiliser
- Les données montrent que Claude Code consomme 5x plus de tokens que d'autres harnesses pour les mêmes tâches, suggérant une optimisation inefficace qui enrichit Cursor sans bénéficier l'utilisateur
- Le comportement devient progressivement plus agressif envers les clients payants existants (augmentation des prix, suppression de transparence), rappelant les pratiques d'enshittification classiques
