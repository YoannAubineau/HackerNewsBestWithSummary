## Résumé de l'article

Delta est une nouvelle application multiplayer créée par l'équipe de Zed pour permettre aux développeurs et aux agents IA de collaborer en gardant le code et les conversations interconnectés. Elle s'appuie sur DeltaDB, une base de données qui réplique en temps réel les conversations et l'arborescence du projet pour tous les participants.

- DeltaDB synchronise le code et les conversations en temps réel entre les participants, fonctionnant avec les dépôts Git existants et capturant chaque modification entre les commits
- Les commentaires restent ancrés au code au fil de son évolution, contrairement aux plateformes basées sur les commits où ils deviennent obsolètes ; l'agent participe au thread avec le même contexte que les humains
- Les équipes peuvent inviter des collaborateurs pour explorer les threads, commenter en direct et continuer les tâches, chacun ayant sa copie locale du code synchronisée en temps réel
- Delta est accessible sur le web (delta.dev) via WebAssembly et WebGL, sans installation requise ; elle s'intègre aussi avec des outils tiers comme Claude Code
- L'interface affiche les diffs complets et les transcriptions entières sans troncature, permettant de commenter n'importe quelle partie de la conversation ou du code avec un positionnement du curseur précis

## Discussion sur Hacker News (107 commentaires)

**Avis positifs** :
- Les commentaires inline sur les réponses d'agents offrent une bien meilleure ergonomie pour guider et itérer avec précision, comparé à l'écriture de réponses textuelles longues
- Préserver les transcriptions des conversations avec agents permet de récupérer le contexte et l'intent des décisions, de retracer comment les problèmes ont été résolus précédemment, et d'identifier les cas limites oubliés
- Pour certains workflows (reviewing, debugging, mentoring juniors), avoir accès aux conversations d'agents d'autres développeurs offre de la valeur pédagogique et de traçabilité
- Delta offre une expérience intéressante pour travailler avec plusieurs fournisseurs de modèles en parallèle, contrairement à des outils monolithiques comme Codex Desktop

**Avis négatifs** :
- Les résumés AI de code sont souvent trop verbeux et perdent en clarté : les paragraphes méandreux remplacent mal les snippets concis, et les cas limites importants sont régulièrement omis
- La plupart des utilisateurs ne demandent jamais le codage collaboratif multiutilisateur et trouvent peu d'utilité pratique à cette fonctionnalité, malgré son coût de développement
- Garder des centaines de lignes de conversations n'est pas une bonne stratégie de documentation : le code bien structuré et commenté reste supérieur, et se replonger dans les anciennes transcriptions n'est pas scalable
- Delta crée de la dépendance propriétaire (lock-in) contrairement à Zed qui est open source, et représente un risque pour les utilisateurs long terme
- Zed néglige ses problèmes fondamentaux (bugs, rough edges, expérience d'édition de base) pour se concentrer sur des features AI hype, écartant les utilisateurs qui veulent un simple éditeur de code moderne sans AI
