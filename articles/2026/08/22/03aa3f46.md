## Discussion sur Hacker News (54 commentaires)

**Avis positifs** :
- Une collection d'opinions utiles et facile à parcourir pour découvrir et mémoriser des fonctionnalités web natives souvent oubliées
- Approche pédagogique bienvenue : distinguer les capacités d'entrée (fine/coarse pointer) plutôt que deviner le type d'appareil est une meilleure pratique
- URLs stables par note permettant le partage, le signet et l'indexation indépendante; navigation dédiée favorise l'extensibilité du contenu
- Approche minimaliste sans framework appréciée, particulièrement pour montrer ce qu'on peut faire en HTML/CSS natif plutôt qu'en React

**Avis négatifs** :
- Absence totale de démonstrations interactives ou visuelles : le site présente du code sans montrer les résultats, rendant difficile la compréhension immédiate et comparaison entre appareils
- Titres trompeurs et contenus mal cadrés (ex: bash mélangé avec du HTML/CSS) ; certains points ne livrent pas ce que le titre promet
- Certains conseils sont nuancés ou mauvais : cacher les barres de défilement prive l'utilisateur d'informations cruciales sur sa position et l'ampleur du contenu, au-delà des rares cas valides
- Manque d'informations sur la compatibilité des navigateurs : les nouvelles fonctionnalités CSS peuvent être surévaluées sans liens vers caniuse.com ou MDN pour vérifier le support réel
