## Discussion sur Hacker News (21 commentaires)

**Avis positifs** :
- Outil pratique et attendu pour les professionnels de l'impression 3D qui reçoivent régulièrement des versions modifiées de fichiers STL sans traçabilité claire des changements
- Architecture privacy-first exécutée entièrement côté client en Web Worker, sans upload serveur, rassurant pour les données sensibles
- Stack technique moderne et robuste (React, TypeScript, React Three Fiber) avec moteur de diff voxel custom adaptant aux STL réelles plutôt qu'à des topologies CSG idéalisées
- Potentiel d'intégration dans des workflows CI/CD ou GitHub pour automatiser les comparaisons 3D entre branches/PR
- Utilité reconnue pour comparer les outputs de générateurs 3D et évaluer les différences quantitativement

**Avis négatifs** :
- Site web du projet non responsive sur mobile et affichage de texte coupé, nuisant à l'accessibilité
- Limitations fonctionnelles détectées : ignorance des groupes multiples dans les OBJ, absence d'avertissement quand le même fichier est comparé à lui-même
- Comportement par défaut des viewports indépendants frustrant : les utilisateurs s'attendent intuitivement à une rotation/transformation synchronisée entre les trois panneaux
- Demo par défaut peu intéressante et peu représentative de cas d'usage complexes réels
- Affirmation sur CGAL contestée : l'outil ne requiert pas une topologie CSG propre et supporte déjà les polygon soups nativement

**Top commentaires** :

- [agys](https://news.ycombinator.com/item?id=49144764) : A nice feature to add could be a synchronized transform: when rotating one viewport the other two rotate along \(optional\).
- [Agingcoder](https://news.ycombinator.com/item?id=49147887) : Ok so stl here is not standard template library. I was very confused for a minute.
- [progbits](https://news.ycombinator.com/item?id=49144323) : Looks handy. Feature suggestion: locked views so all three viewports rotate together.
