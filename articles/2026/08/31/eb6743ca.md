## Résumé de l'article

FreeCORE est un projet qui maintient de manière indépendante TrueNAS CORE 13.3 comme système d'exploitation basé sur FreeBSD. Le projet a atteint une version stable avec la 15.0-U1, et les utilisateurs de TrueNAS CORE 13.3 peuvent effectuer une mise à niveau directe vers la version 15.0 avant de continuer sur le cycle de mise à jour du projet.

- FreeCORE est une continuité indépendante de TrueNAS CORE 13.3 construite sur FreeBSD
- La version 15.0-U1 est considérée comme stable
- Les systèmes TrueNAS CORE 13.3 existants peuvent migrer directement vers la version 15.0 sur place
- Le projet s'appuie sur les contributions antérieures de FreeNAS, TrueNAS CORE et OpenZFS, avec attribution des droits d'auteur

## Discussion sur Hacker News (97 commentaires)

**Avis positifs** :
- FreeCORE offre une continuation bienvenue pour les utilisateurs attachés à FreeBSD et ZFS, permettant de rester sur une base stable sans être forcé de migrer vers Linux/Debian
- FreeBSD avec ZFS est généralement plus stable et prévisible pour les appliances de stockage une fois configuré, comparé aux variations de distributions Linux
- L'existence de forked communautaires comme FreeCORE et BSDnas répond au besoin réel de maintenir une alternative open-source à TrueNAS après la discontinuation officielle de CORE
- Pour les administrateurs qui maîtrisent la ligne de commande, une approche minimaliste sur FreeBSD/Linux pur offre davantage de contrôle et de stabilité long terme

**Avis négatifs** :
- TrueNAS a cessé de publier ses scripts de compilation, compromettant l'esprit open-source malgré la disponibilité théorique du code source
- Les utilisateurs craignent que FreeCORE et les forks similaires manquent de financement et de maintenance durable, créant un risque de discontinuation et d'obsolescence logicielle
- La migration vers des forks non-officiels présente un risque : pas de garantie de sécurité, pas de voie claire pour les mises à jour, contrairement à TrueNAS SCALE soutenu commercialement
- TrueNAS SCALE (Linux/Debian) offre une meilleure compatibilité matérielle, des mises à jour continues, et un environnement moins « chaotique » qu'une base FreeBSD de niche
